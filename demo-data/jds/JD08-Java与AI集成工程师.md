# [演示] Java与AI集成工程师

【虚构演示岗位，不代表真实招聘或市场薪资】
岗位：Java与AI集成工程师
团队：虚构智能业务团队
地点：上海
测试薪资：20–34k/月，仅为界面与解析测试。

岗位职责：
1. 负责将知识问答和结构化模型输出接入现有业务系统。
2. 设计Java与AI服务边界；处理超时、权限、流式输出和失败恢复。
3. 与产品及测试人员确认验收标准，维护接口与交付说明。

任职要求：
1. 具备3年及以上相关项目经验，本科或同等项目能力。
2. 能结合项目解释Java、Spring Boot、RAG、MySQL的实际使用、异常边界与验证方法。
3. 能说明个人负责的模块，不以技术名词出现次数代替实际能力。

加分项：Python、SSE、LangChain，不作为未满足即淘汰的依据。

面试建议：围绕具体问题、处理过程和验证证据展开，核对简历中未明确的能力。最终判断由面试人与HR进行。
