# [演示] Java业务开发工程师｜初级

【虚构演示岗位，不代表真实招聘或市场薪资】
岗位：Java业务开发工程师｜初级
团队：虚构业务研发团队
地点：成都
测试薪资：10–16k/月，仅为界面与解析测试。

岗位职责：
1. 负责企业管理系统的业务接口、数据校验和联调。
2. 独立交付小型业务模块；编写接口文档和关键业务测试。
3. 与产品及测试人员确认验收标准，维护接口与交付说明。

任职要求：
1. 具备1年及以上相关项目经验，本科或同等项目能力。
2. 能结合项目解释Java、Spring Boot、MySQL的实际使用、异常边界与验证方法。
3. 能说明个人负责的模块，不以技术名词出现次数代替实际能力。

加分项：MyBatis、Git、单元测试，不作为未满足即淘汰的依据。

面试建议：围绕具体问题、处理过程和验证证据展开，核对简历中未明确的能力。最终判断由面试人与HR进行。
