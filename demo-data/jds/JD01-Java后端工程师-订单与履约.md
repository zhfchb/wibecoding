# [演示] Java后端工程师｜订单与履约

【虚构演示岗位，不代表真实招聘或市场薪资】
岗位：Java后端工程师｜订单与履约
团队：虚构交易研发团队
地点：上海
测试薪资：18–28k/月，仅为界面与解析测试。

岗位职责：
1. 负责订单创建、库存预占、支付回调与履约状态同步。
2. 实现幂等回调与超时关单；为库存扣减设计并发控制和补偿方案。
3. 与产品及测试人员确认验收标准，维护接口与交付说明。

任职要求：
1. 具备3年及以上相关项目经验，本科或同等项目能力。
2. 能结合项目解释Java、Spring Boot、MySQL、Redis的实际使用、异常边界与验证方法。
3. 能说明个人负责的模块，不以技术名词出现次数代替实际能力。

加分项：RabbitMQ、Seata、Docker，不作为未满足即淘汰的依据。

面试建议：围绕具体问题、处理过程和验证证据展开，核对简历中未明确的能力。最终判断由面试人与HR进行。
