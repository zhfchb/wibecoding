# [演示] Java搜索服务工程师

【虚构演示岗位，不代表真实招聘或市场薪资】
岗位：Java搜索服务工程师
团队：虚构搜索研发团队
地点：北京
测试薪资：22–35k/月，仅为界面与解析测试。

岗位职责：
1. 负责业务搜索索引、增量同步和检索接口开发。
2. 设计索引字段与同步补偿；用测试查询集验证排序和召回变化。
3. 与产品及测试人员确认验收标准，维护接口与交付说明。

任职要求：
1. 具备4年及以上相关项目经验，本科或同等项目能力。
2. 能结合项目解释Java、Elasticsearch、MySQL、Spring Boot的实际使用、异常边界与验证方法。
3. 能说明个人负责的模块，不以技术名词出现次数代替实际能力。

加分项：Kafka、Redis、搜索评测，不作为未满足即淘汰的依据。

面试建议：围绕具体问题、处理过程和验证证据展开，核对简历中未明确的能力。最终判断由面试人与HR进行。
