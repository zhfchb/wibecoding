# 招聘资料库学习素材

全部内容为虚构团队的练习设定，不代表真实企业制度、市场薪资或法律要求。适用于本项目“招聘资料库 → 资料问答”的上传、检索、引用与拒答练习。

## 上传方法

1. 使用你正在学习的HR账号登录，进入“招聘资料库”。私人资料库按上传者隔离，使用同一个账号进行后续问答。
2. 上传本目录 `upload/` 下的7个 `.md` 文件，等待每个文件完成。当前界面若只支持逐份上传，就按编号依次上传。
3. 进入“资料问答”，新建会话，先问“Java后端岗位的必须技能是什么？”。检查答案和来源文件。
4. 再按[学习练习与预期答案](../../docs/development/招聘资料库学习练习.md)测试单文档、跨文档和资料不足场景。

只上传 `upload/` 内的资料；本README和预期答案不上传，避免把答案提示混入知识库。重复练习前先查看已有资料，不必反复上传同一份文件。本次仅生成文件，没有自动上传或调用模型。
