# 本轮功能收尾基线（2026-11-16）

当前交付范围为公司内部技术招聘协作的学习、演示和本地小范围试用。已确认的必修待办纳入本轮收尾，新的业务需求另行规划。

## 已交付范围

| 范围 | 可使用的能力 |
| --- | --- |
| 公司与岗位 | 公司资料、部门、HR/面试官成员、岗位和JD、显式岗位共享 |
| 简历与初筛 | 解析、失败重新解析、匹配参考和证据、人工初筛、后台任务 |
| 面试与协作 | 题目/报告、分轮分配、排期与冲突检查、面试官待办、私有草稿与提交锁定 |
| 招聘推进 | HR下一步提示、沟通跟进、岗位创建人汇总、人工结果与归档历史 |
| 招聘资料支持 | 批量上传、明确失败恢复、可展开Markdown来源、资料问答、草稿内容审核 |
| 会话 | 首次问题本地默认标题、手工重命名、置顶、刷新恢复、用户隔离 |

默认标题取首次已保存用户问题，清理Markdown与空白后截取，含省略号最多24个UTF-16单元。标题不做语义概括，不额外调用模型；新建不弹命名框。手工名称优先，后续问题/回答不覆盖；旧会话兼容，缺少用户问题显示“新会话”。首次问答失败而没有保存历史时，不创建空白历史记录。

重命名预填和编辑最多80个UTF-16单元，与Java校验一致；省略号计入总长，截断不保留半个代理对。常用汉字占1个单元，部分表情占2个。

- 资料库页面回归覆盖83字符历史预填限为80、100字符输入限为80、重命名刷新恢复；同时复查来源、Markdown、批量失败重试。

- 原招聘协作真实复核见[招聘流程验收](HIRING_WORKFLOW_20261116.md)，真实模型小样本证据见[运行复核](RUNTIME_UPGRADE_20261109.md)。本轮没有把模拟模型测试写成新的真实模型质量结论。

## 运行与使用

本机Java容器已更新，前端Vite使用当前代码，刷新即可使用。标题修复不增加数据库迁移、不改模型密钥、不覆盖原会话或手工名称；真实复核仅创建独立演示账号和虚构会话。

使用顺序见[招聘流程操作指南](../product/招聘流程操作指南.md)。HR从岗位页推进，面试官从面试工作台处理获分配任务。私有资料/草稿边界及人工决策保持有效。
