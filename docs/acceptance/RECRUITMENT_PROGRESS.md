# 招聘进度总览（第八阶段）

> 后续状态：真实环境总览与结果/评价联动已在2026-11-08单样本流程验证，见[真实验收](LIVE_RECRUITMENT_ACCEPTANCE.md)。本文末尾的待联调说明是第八阶段记录，大数据性能仍待验证。

岗位工作台新增总览：全部候选人数、待定/录用/淘汰/退出分布及归档数量。支持姓名/文件名搜索、招聘结果、归档状态、跟进状态组合筛选，分页展示；计数为筛选前的当前岗位总量，筛选命中数另行显示。

“已有评价、仍待决定”指最终结果待定、未归档且至少有一条有效已提交面试评价。仅作提示，不自动决定通过/淘汰，不透露草稿内容。已撤销分配不计入提交数量。同一候选人多份简历分别统计，不做身份去重，也不是招聘转化率或历史趋势报表。

创建人、当前EDITOR与VIEWER均可读，结果写入继续遵守第七阶段权限；面试官不能进入总览。总览中的结果入口可直接查看历史或记录结果，写入成功自动刷新；原简历列表写入、上传/删除后也刷新。支持手动刷新及失败重试，无自动轮询。只展示当前岗位及其数据owner的简历；文件名限定同owner未删除文档，不因重复文档元数据增加行数。

接口：GET `/api/v1/recruitment/positions/{id}/progress`，返回每条简历的id、候选人名、文件名、当前最终结果、归档状态及已提交评价数；没有最终结果的旧记录视为待定/未归档，读操作不写入数据库。单次SQL快照保证各计数来源一致。当前一次返回岗位全部记录并在浏览器分页/筛选，尚未进行大规模岗位性能验证；服务端分页可在数据规模需要时独立实现。

本阶段无数据库迁移、外部服务或环境变量变化。沿用此前结果表，已有库须完成第七阶段迁移。未新增模型调用或外部通知。

验证：新增4项后端测试，覆盖默认记录、岗位owner隔离、结果/归档、已提交/草稿/撤销计数、读取权限与撤权、文件名归属及重复元数据。全量测试及前端构建结果见变更日志。`scripts/verify-progress-ui.py`使用模拟API验证失败重试、汇总、组合筛选、跟进提示、文件名搜索、只读结果入口及390px无页面横向溢出；原结果流程与招聘协作页面回归通过。按webapp-testing技能使用原生Python Playwright，未写真实业务记录。真实运行接口联调与大数据性能尚未验证。
