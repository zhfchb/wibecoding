# 招聘协作流程验收（2026-11-16）

## 本轮实现

1. HR岗位页显示招聘流程与下一步提示，区分解析、初筛、待分配、待排期、待提交评价；读取失败明确提示。关闭岗位显示历史整理提示。
2. 面试官工作台按待排期、待准备、进行中、待提交评价、已提交、已取消/未到场分组统计并筛选，保留原草稿、提交锁定与权限校验。
3. 面试分配支持第1～10轮，同候选人/面试官/轮次重复分配复用记录；不同轮次的排期和评价独立，旧记录默认第1轮。题目仍按候选人共享，不声称各轮独立生成题库。
4. 候选人追加式跟进与负责人汇总记录，含记录人、时间、分页及选填下次跟进时间。EDITOR可写跟进，岗位创建人可写汇总，VIEWER只读；面试官不能读取HR记录。负责人沿用岗位创建人，没有新增独立用人经理角色。
5. 保存结果未知时复用请求标识与原内容确认；相同请求内容不同返回冲突。删除源简历连带清理记录，不补造历史沟通。

轮次不会自动晋级，跟进时间不发送提醒；负责人汇总不自动修改初筛、面试评价或最终结果。招聘编制审批、外部招聘渠道、通知发送、Offer与入职仍未实现。
