# 择序 · 技术招聘协作工作台

当前状态更新于2026-11-09。核心功能已开发完成，已通过2026-11-08单样本真实模型招聘流程验收，可用于学习、演示和试用；生产部署、压测及备份恢复演练仍待执行。

## 用户与目标

服务中小型技术团队的公司管理员、HR/招聘负责人、技术面试官。将公司部门、岗位要求、简历、评分依据、面试和人工结果放到一个工作流程中。AI提取与整理信息、提供建议，最终初筛与招聘结果由人确认。候选人暂不直接登录。

## 当前流程

1. 管理员完善公司资料、省市、行业和规模，新增HR或面试官，维护平级部门。
2. HR创建岗位或导入JD，关联启用部门，上传简历并核对解析结果；失败资料可后台重新解析。
3. 发起持久化匹配任务，查看规则/语义评分、技能命中及缺失，人工决定初筛。
4. 创建人可向指定同公司成员授权VIEWER只读或EDITOR招聘流程协作，权限不等于全公司公开。
5. 生成定制题目和报告，分配面试官、安排明确时区的时间，处理冲突、改期或取消。
6. 面试官仅查看本人获分配候选人的必要资料，私有草稿提交后锁定；有排期时须到结束时间才能提交。
7. HR记录待定/录用/淘汰/退出，填写原因；归档后可按版本重新开启，保留操作历史。
8. 岗位进度总览显示结果分布、归档数量，支持搜索和组合筛选，提示已有评价但尚未决定的人选。

招聘资料库、资料问答、SSE和Agent工作流属于招聘支持能力。内容审核用于资料草稿的人工审核，不等同于候选人审批。

## 权限和数据边界

- 公司角色与系统ADMIN/USER独立；系统ADMIN不绕过岗位权限。
- 岗位创建人管理岗位、上传删除和授权；EDITOR可推进初筛、任务、面试及结果；VIEWER只读。
- 面试官不通过岗位授权获得完整招聘资料，草稿仅本人可见，提交评价供招聘负责人参考。
- 数据owner与实际actor分别记录；后台任务校验授权版本，撤权与重授不恢复旧任务权限。
- 私人知识库和聊天不随岗位共享。归档仅锁定结果，不自动取消任务、撤销面试或删除资料。
- 总览按简历记录统计，不自动合并同一人的多份简历，不推断历史转化率。
