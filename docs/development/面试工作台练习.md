# 面试工作台练习

本机演示岗位为“[演示] 面试工作台练习专用”，岗位ID为27。所有候选人、题目、历史排期和预填评价均为虚构预设；没有调用模型、解析或向量化，也不代表真实面试发生过。

## 登录和操作

1. 退出admin账号，使用面试官`interview_demo`登录，默认进入“面试工作台”。密码保存在本机被Git忽略的`outputs/acceptance/interview-demo/test-account.txt`。
2. 林同学：点击“准备面试与评价”，查看岗位要求和3道演示题，修改优势证据与待核实问题，先“保存草稿”。再次打开确认保留；填写1～5分、面试建议、评价总结后“提交评价”。提交后锁定。
3. 周同学：未来面试可预览题目、先存草稿；计划结束前禁止提交评价。保存排期不等于已发送邀请。
4. 陈同学：查看已提交的演示评价，确认不可再次编辑。
5. 换回admin，在该演示岗位找到候选人，点击“面试分工”查看面试官分配及已提交的评价。未提交的草稿仅面试官本人可见，面试建议不自动改变HR初筛或最终招聘结果。

完整业务流程是：公司管理员创建面试官成员 → HR在候选人上分配面试官、安排时间 → 面试官查看资料、准备问题、保存个人草稿 → 面试后提交评价 → HR参考评价记录最终决定。

## 数据准备与复核

- `python scripts/seed-interview-demo.py`：仅本地运行，默认admin账号，可通过DEMO_USERNAME/DEMO_PASSWORD指定；创建同公司面试官和演示岗位，以API分配面试、设置未来排期、保存评价。
- 候选人与题目采用明确标记的结构化fixture导入；过去排期连同初始历史记录以fixture插入，再通过正式接口确认完成，以便立即练习评价，不修改系统时钟或放宽排期规则。
- 脚本重复运行复用已有记录，保留已修改/已提交的评价，不重置用户练习。不要把该脚本用于真实候选人。
- `python scripts/verify-interview-demo.py`：真实页面只读检查3种状态，无新模型调用，不提交用户评价；本地截图与结果在`outputs/acceptance/interview-demo/`。
