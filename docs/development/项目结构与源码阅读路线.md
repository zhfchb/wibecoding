# 项目结构与源码阅读路线

第一版按业务模块组织，Java 仍是一个 Spring Boot 应用，Python 仍是一个 FastAPI 服务。本轮仅整理结构，HTTP、数据库、角色权限和运行参数保持兼容。

## 目录归属

| 位置 | 职责 |
| --- | --- |
| src/main/java/com/example/agent/company | 公司、部门与成员 |
| src/main/java/com/example/agent/recruitment | 岗位、简历、匹配、跟进、结果和岗位权限 |
| src/main/java/com/example/agent/interview | 面试资料、分配、排期、轮次和评价 |
| src/main/java/com/example/agent/knowledge | 上传、切片、检索、向量与文档生命周期 |
| src/main/java/com/example/agent/chat | 问答、会话、来源和会话存储 |
| src/main/java/com/example/agent/review | 内容审核和审核任务状态 |
| src/main/java/com/example/agent/assistant | 通用 Agent 入口 |
| src/main/java/com/example/agent/integration/ai | Python AI 网关 |
| src/main/java/com/example/agent/security | 登录、用户、JWT 和鉴权 |
| src/main/java/com/example/agent/config、exception | 共用基础配置与异常处理 |
| src/test/java/com/example/agent | 按对应业务归拢测试 |
| frontend/src/features | auth/company/recruitment/interview/chat/knowledge/review 页面、组件、钩子及业务 API |
| frontend/src/shared | 共用 HTTP 客户端和页面介绍组件 |
| ai-service/app/features | chat/recruitment/resumes/vectors/workflows 路由 |
| ai-service/app/core | 认证、模型配置和网络适配 |
| deploy、scripts、docs | 部署、脚本和分类文档 |

Java 每个业务按规模使用 api、dto、service、entity、mapper 等子包，已有实现放在 service/impl 或业务专用子包。接口与类可以在同一个业务模块中：接口表达调用约定，实现承担具体行为；本轮保留已有接口，不为每个类机械增加接口，也不批量删除接口。

## 阅读顺序

先读[业务操作指南](../product/招聘流程操作指南.md)，带着一个页面动作追踪请求。

1. **岗位与简历**：[岗位页](../../frontend/src/features/recruitment/pages/PositionWorkbenchPage.jsx) → [招聘 API](../../frontend/src/features/recruitment/api.js) → [RecruitmentController](../../src/main/java/com/example/agent/recruitment/api/RecruitmentController.java) → [RecruitmentServiceImpl](../../src/main/java/com/example/agent/recruitment/service/impl/RecruitmentServiceImpl.java)。匹配和解析任务继续看 recruitment/matching、recruitment/resumes。
2. **资料问答**：[ChatPage](../../frontend/src/features/chat/pages/ChatPage.jsx) → [聊天 API](../../frontend/src/features/chat/api.js) → [ChatController](../../src/main/java/com/example/agent/chat/api/ChatController.java) → [RagChatServiceImpl](../../src/main/java/com/example/agent/chat/service/impl/RagChatServiceImpl.java) → [AiGateway](../../src/main/java/com/example/agent/integration/ai/AiGateway.java) → [Python chat](../../ai-service/app/features/chat.py)。检索回调继续读 [InternalRetrievalController](../../src/main/java/com/example/agent/knowledge/api/InternalRetrievalController.java)。
3. **上传资料**：[KnowledgePage](../../frontend/src/features/knowledge/pages/KnowledgePage.jsx) → [KnowledgeController](../../src/main/java/com/example/agent/knowledge/api/KnowledgeController.java) → [KnowledgeServiceImpl](../../src/main/java/com/example/agent/knowledge/service/impl/KnowledgeServiceImpl.java)，再看 knowledge/rag 和 DocumentLifecycle。
4. **面试官工作台**：[InterviewWorkbenchPage](../../frontend/src/features/interview/pages/InterviewWorkbenchPage.jsx) → [面试 API](../../frontend/src/features/interview/api.js) → [InterviewAssignmentController](../../src/main/java/com/example/agent/interview/api/InterviewAssignmentController.java) → interview/service，再结合 [迁移说明](../../deploy/migrations/README.md) 看持久化。
5. **启动与安全**：[Java 入口](../../src/main/java/com/example/agent/AgentApplication.java)、[Python 入口](../../ai-service/app/main.py)、security 和共享 HTTP 客户端，最后阅读对应业务测试。

## 边界与维护约定

招聘负责岗位权限与候选人，面试复用这些权限和数据；招聘删除流程也会调用面试清理。因此当前存在显式跨模块协作，并未实现严格单向依赖或完整 DDD 隔离。共享基础层不应反向收集业务逻辑；模型 SDK 通过 AI 网关及 Python 服务使用。

Java 启动类、Python app.main:app、前端路由、脚本命令和数据库表名保留。新增代码优先放到所属业务，不再恢复根目录大 service/controller 集合。历史文档保留原时间语境；学习以本页和当前代码为准。

脚本使用见 [scripts 导航](../../scripts/README.md)，本轮验证见[结构整理验收](../acceptance/PROJECT_STRUCTURE_20261116.md)。
