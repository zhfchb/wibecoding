# 地区数据来源

来源：https://github.com/airyland/china-area-data ，固定 npm 版本 china-area-data@5.0.1。
快照：src/main/resources/company-regions.json。仅保留前两级；直辖市使用自身作为城市，不把辖区当作城市。
历史数据快照不代表最新行政区划；更新需独立验证。运行时不依赖外网。
